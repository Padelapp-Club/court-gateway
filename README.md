# court-gateway

Сервис, который даёт партнёрам клуба (агрегаторам, приложениям для игроков) единый API
поверх CRM клуба: корты, часы работы, занятость, цены и бронирование.

- **Ничего не хранит.** Каждый ответ собирается из CRM в момент запроса. Базы данных нет;
  в памяти живёт только токен входа в CRM до истечения его срока.
- **Не отдаёт данные ваших клиентов.** Брони, заведённые клубом, партнёр видит только как
  «корт занят с … до …» — без имён, телефонов, почты и комментариев.
- **Отменить можно только своё.** Партнёр не может удалить бронь, которую завёл клуб или
  другой партнёр.
- **Один бинарный файл.** Запускается на Linux, macOS и Windows; для работы нужен только файл
  конфигурации и переменные окружения.

Поддерживаемые CRM: `viva`. Тип `demo` — учебный, хранит брони в памяти до перезапуска.

## Быстрый старт

1. Скопируйте пример конфигурации и поправьте его под свой клуб:

   ```sh
   cp gateway.example.yaml gateway.yaml
   cp .env.example .env
   ```

2. Заполните `gateway.yaml`:

   ```yaml
   club:
     id: my-club
     name: "Мой клуб"
   listen: ":8080"
   crm:
     type: viva
     username: admin@example.com      # логин администратора CRM
     studio: <идентификатор студии>
   venue:
     timezone: Europe/Moscow
     slot_minutes: 30
     hours:
       mon-fri: "07:00-23:00"
       sat-sun: "08:00-23:00"
   courts:
     - id: court-1
       name: "Корт 1"
       viva_room: <идентификатор комнаты корта>
       price_list: <идентификатор прайс-листа>   # необязательно
   services:                                      # необязательно
     booking: { direction: 1, type: 1 }
   partners:
     - name: aggregator
       key_env: PARTNER_KEY_1
       scopes: [read, book]
   ```

   - `services.booking` — услуга CRM, которой создаётся бронь партнёра. Если раздела нет,
     бронь создаётся технической блокировкой корта. `services.tournament` — то же для турниров.
   - `scopes`: `read` — только сверка (корты, занятость, цены), `book` — ещё и бронирование.
   - Часы работы задаются по дням: `mon`, `tue`, `wed`, `thu`, `fri`, `sat`, `sun`, диапазоны
     вида `mon-fri`; выходной — `closed`. Конец дня — `24:00`.

3. Заполните `.env` — секреты хранятся только там, не в `gateway.yaml`:

   ```sh
   CRM_PASSWORD=пароль-администратора-CRM
   PARTNER_KEY_1=длинный-случайный-ключ   # не короче 24 символов: openssl rand -hex 32
   ```

4. Запустите:

   ```sh
   set -a; . ./.env; set +a
   court-gateway serve -config gateway.yaml
   ```

   Если в конфигурации ошибка, сервис не запустится и перечислит все найденные проблемы.

5. Проверьте готовность:

   ```sh
   court-gateway healthcheck -config gateway.yaml
   ```

   Код выхода 0 — сервис вошёл в CRM и видит занятость. Иначе в ответе будет причина:
   `CRM_AUTH_FAILED` (неверный логин или пароль), `CRM_UNREACHABLE` (CRM недоступна) и т. п.

## API для партнёров

Все запросы, кроме `/health/*`, требуют заголовка `Authorization: Bearer <ключ партнёра>`.
Время — в формате RFC 3339, цены — в целых рублях.

| Запрос | Что делает |
|---|---|
| `GET /health/live` · `GET /health/ready` | сервис жив · готов работать с CRM |
| `GET /v1/clubs` · `GET /v1/clubs/{club}` | клуб: часовой пояс, шаг сетки, часы работы, возможности |
| `GET /v1/clubs/{club}/courts` | корты |
| `GET /v1/clubs/{club}/occupancy?from=&to=[&court=]` | занятость кортов за период |
| `GET /v1/clubs/{club}/prices?court=&date=` | цены корта на дату |
| `GET /v1/clubs/{club}/quote?court=&start=&end=` | стоимость интервала |
| `POST /v1/clubs/{club}/bookings` | создать бронь `{court, start, end, kind: game\|tournament, note}` |
| `GET` · `DELETE /v1/clubs/{club}/bookings/{id}` | прочитать · отменить бронь |
| `POST /v1/clubs/{club}/bookings/{id}/payment` | отметить оплату (если CRM умеет) |

Ошибки приходят в виде `{"code": "...", "message": "...", "request_id": "..."}`.

## Что важно знать

- **Прошедшие даты.** CRM не отдаёт брони за прошлые дни, поэтому занятость за прошлое
  приходит с пометкой `"complete": false` — это не значит, что корт был свободен.
- **Повтор после таймаута.** Сервис не хранит запросы и не может распознать повтор. Если
  ответ на создание брони не пришёл, проверьте занятость, прежде чем повторять.
- **Шифрование.** Сервис отдаёт обычный HTTP. Если он доступен из интернета, поставьте
  перед ним HTTPS-прокси.
